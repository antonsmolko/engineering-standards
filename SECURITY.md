# Security

Do not post secrets, private materials or sensitive vulnerability details in
public issues or pull requests.

Use this repository's private vulnerability reporting when it is available.
Otherwise, contact the repository owner,
[@antonsmolko](https://github.com/antonsmolko), to request a private channel;
include no sensitive details in the public request.

Verification runs on GitHub-hosted runners with read-only repository permissions
and no publication credentials. Successful checks do not replace a manual audit
of every release tarball for secrets, private or product-specific information,
and redistribution rights. Publication requires separate explicit approval.
