Для каждого нужна ветка своей задачи от текущего main. Changesets, CI, принятие реальных стандартов и публикация — отдельные изменения, а не скрытые задачи этого PR.

План ведётся на русском; публикуемые стандарты/README и примеры потребительских инструкций — на английском. Возможные две языковые версии не входят в задачи этого change.
