# Ручное подключение потребителя

## Purpose

Позволить людям и AI применять выбранные установленные пакеты стандартов целиком через короткую, вручную поддерживаемую инструкцию потребителя.

## ADDED Requirements

### Requirement: Whole-package adoption
Описанный сценарий подключения SHALL выбирать npm-пакеты, а не отдельные ID требований или профили. Читатели SHALL применять применимые принятые стандарты каждого выбранного пакета целиком; выбор пакета не отменяет метки черновиков и не является принятием содержания.

#### Scenario: Select core and TypeScript
- **WHEN** потребитель выбирает стандарты core и TypeScript
- **THEN** его инструкции ссылаются на два пакета как целые наборы документов без файла выбора правил или resolver

### Requirement: Manual instruction entry point
Репозиторий SHALL описывать обычную npm-установку и содержать копируемый пример AGENTS.md со ссылками на README каждого выбранного установленного пакета. Пример MUST требовать чтения связанных стандартов; конкретный AI-поставщик или автоматическая интерпретация не требуются.

#### Scenario: Add instructions to a consumer
- **WHEN** разработчик следует примеру подключения в npm-проекте
- **THEN** он может установить выбранные пакеты и вручную добавить действительные пути README в AGENTS.md без CLI продукта

### Requirement: Installation does not manage consumer instructions
Установка или обновление пакетов MUST NOT создавать или переписывать AGENTS.md, другие AI-инструкции или lint/format-конфиги потребителя. npm MAY менять обычные файлы зависимостей и lockfile; инструкции редактируются явным действием разработчика.

#### Scenario: Preserve existing instructions
- **WHEN** пакеты устанавливаются в проект с существующим AGENTS.md
- **THEN** этот файл и существующие lint/format-конфиги остаются побайтно неизменными

### Requirement: Missing packages and upgrades are explicit
Руководство SHALL пояснять, что пути README требуют установленных зависимостей, а отсутствующий пакет нужно установить до использования его стандартов. Обновление SHALL выполняться через npm с чтением changelog; совместимость проверяется чтением рекомендаций, а не собственным семантическим движком.

#### Scenario: Dependencies are not installed
- **WHEN** документированный путь README отсутствует в свежем checkout
- **THEN** руководство указывает установку зависимостей как предварительное условие, не утверждая, что AI уже может читать эти стандарты

#### Scenario: Upgrade selected standards
- **WHEN** разработчик обновляет выбранный пакет через npm
- **THEN** он читает changelog и рекомендации по совместимости в README без запуска Engist sync
